**ویدئوی اینستاگرام و دکمهٔ شناسایی موسیقی (Cloudflare، وابسته به منابع رایگان):** [INSTAGRAM.md](INSTAGRAM.md) — لینک ریلز/پست عمومی؛ بدون کلید یا API پولی تازه. کاربر کارکرد لینک نمونه را تأیید کرده؛ شناسایی زندهٔ آهنگ مستقلاً تأیید نشده؛ فایل کامل آهنگ در پاسخ منبع فعلی موجود نیست و نام/لینک رسمی جایگزین می‌شود.

**قیمت دلار و طلا، هوا و هشدار بارش:** [INTERNET.md](INTERNET.md) — در نسخهٔ Cloudflare، با کلید جداگانه برای قیمت‌ها.

## نصب و راه‌اندازی

۱. روی یک سرور یا کامپیوتر همیشه‌روشن با **Node.js 22 یا جدیدتر** کار کنید. وابستگی اضافی برای ربات لازم نیست.
۲. در تلگرام، از حساب رسمی **@BotFather** با دستور `/newbot` یک ربات بسازید و توکنش را فقط روی سرور خودتان نگه دارید.
۳. از پنل OpenRouter یک کلید API بسازید، اعتبار و سقف هزینه مناسب تعیین کنید و شناسه دقیق مدل موردنظرتان را از همان پنل بردارید. مدل باید قابلیت چت و دستور system داشته باشد. هزینه، محدودیت و سیاست داده هر ارائه‌دهنده متفاوت است؛ رایگان بودن یا محرمانه ماندن داده را فرض نکنید.
۴. در ریشه مخزن:

```sh
cp .env.bot.example .env.bot
chmod 600 .env.bot
```

فایل `.env.bot` را با ویرایشگر روی سرور باز کنید و این متغیرها را پر کنید:

- `TELEGRAM_BOT_TOKEN`: توکن BotFather.
- `OPENROUTER_API_KEY`: کلید OpenRouter.
- `OPENROUTER_MODEL`: شناسه دقیق مدل انتخابی؛ پیش‌فرض یا جایگزین خودکار وجود ندارد.
- `TELEGRAM_ALLOWED_USER_IDS`: برای تست خصوصی، شناسه عددی حساب‌های مجاز با کاما جدا شوند. خالی بودن یعنی هر کسی که ربات را پیدا کند می‌تواند از اعتبار شما مصرف کند. پیشنهاد: قبل از اولین اجرا محدودش کنید.
- `BOT_STYLE`: توضیح لحن خودتان یا نمونه‌های ساختگی و بی‌اطلاعات شخصی. قوانین شفافیت هویت و ایمنی ربات همچنان برقرارند.

**کلیدها را در چت، کد، اسکرین‌شات یا متغیرهای `VITE_*` قرار ندهید.** فایل خصوصی در Git نادیده گرفته می‌شود. اگر کلیدی افشا شد، آن را در سرویس مربوطه باطل و جایگزین کنید.

۵. اجرا:

```sh
npm run bot
```

سپس در چت خصوصی ربات `/start` بفرستید. این برنامه از long polling استفاده می‌کند: دامنه، پورت عمومی و webhook لازم نیست. هم‌زمان فقط یک نسخه با هر توکن اجرا کنید. اگر webhook قدیمی فعال است، برنامه متوقف می‌شود؛ پیش از حذف آن بررسی کنید سرویس دیگری به آن وابسته نباشد. این برنامه خودش webhook را حذف نمی‌کند.

برای اجرای همیشگی از سرویس‌منیجر مثل systemd با کاربر غیرریشه، مسیر کاری مخزن و فرمان `npm run bot` استفاده کنید. خاموش‌شدن ترمینال یا سرور ربات را متوقف می‌کند، مگر سرویس‌منیجر تنظیم شده باشد.

## امکانات و حریم خصوصی

- `/start`: فقط «سلام، چطوری؟ 🙂🌱» و شروع مجدد.
- `/about`: توضیح هویت دیجیتال امیر و نحوهٔ پردازش پیام‌ها.
- `/reset`: حذف حافظه موقت گفتگوی همین کاربر.
- `/privacy`: توضیح ارسال داده به سرویس‌های بیرونی و نگهداری آن.
- `/help`: راهنمای فرمان‌ها.
- فقط چت خصوصی و متن؛ پیام گروه، تصویر و صدا به مدل ارسال نمی‌شوند.
- متن گفتگو روی دیسک یا در لاگ این برنامه نوشته نمی‌شود. تلگرام، OpenRouter، مدل و زیرساخت میزبانی ممکن است سیاست‌های جداگانه داشته باشند.
- حداکثر ۳۰ پیام اخیر (۱۵ رفت‌وبرگشت) برای هر کاربر در حافظه، حداکثر ۵۰۰ کاربر، حذف پس از ۳۰ دقیقه بی‌فعالیتی (پاک‌سازی هر دقیقه) یا راه‌اندازی مجدد. `/reset` داده‌های سرویس‌های بیرونی و پیام‌های تلگرام را حذف نمی‌کند.
- محدودیت ورودی ۶۰۰۰ کاراکتر، خروجی مدل ۳۲۰ توکن و فاصله حداقل ۴ ثانیه میان درخواست‌های هر کاربر؛ این‌ها جایگزین سقف اعتبار در OpenRouter نیستند.

## لحن و ایمنی

لحن پیش‌فرض صمیمی و شنونده است، نه تشخیص‌دهنده یا نصیحت‌گر. ربات ادعا نمی‌کند خودِ صاحب ربات یا درمانگر است. دستور مدل شامل واکنش حمایتی به خطر فوری و تشویق به کمک انسانی است؛ **این دستور تضمین تشخیص بحران یا پاسخ ایمن نیست**. هیچ پایش انسانی یا تماس خودکار با اورژانس وجود ندارد. پیش از انتشار عمومی، پاسخ‌های مدل منتخب را با سناریوهای عادی، خودسرزنشگری، بحران و تلاش برای دورزدن دستورها بررسی کنید. برای خدمات درمانی یا پشتیبانی اضطراری از این نسخه استفاده نکنید.

## آزمون و محدودیت نسخه اولیه

```sh
npm run test:bot
node --check bot/index.mjs
```

آزمون‌های واحد، اتصال ساختگی OpenRouter، حافظه، تفکیک پیام و ساختار دستور ایمنی را می‌سنجند؛ کیفیت پاسخ واقعی یا اتصال زنده را اثبات نمی‌کنند. تست زنده نیازمند کلید معتبر و دسترسی شبکه به `api.telegram.org` و `openrouter.ai` است.

پردازش پیام‌ها در این نسخه سریالی است؛ یک درخواست کند می‌تواند بقیه را منتظر بگذارد. برای تعداد کاربر بالا به صف محدود، هم‌زمانی کنترل‌شده، مانیتورینگ بدون داده حساس و سیاست سوءاستفاده نیاز دارید. تاریخچه با ری‌استارت از بین می‌رود. پیام‌های در حال پردازش هنگام قطعی یا ری‌استارت ممکن است از دست بروند یا تکرار شوند؛ تضمین exactly-once وجود ندارد. کیفیت فارسی و پیروی از دستور ایمنی به مدل انتخابی بستگی دارد.

## شخصیت امیر

نام شخصیت گفتگو «امیر» است. در پاسخ به سؤال نام، «امیرم» می‌گوید؛ دستور `/about` روشن می‌کند پاسخ‌ها با هوش مصنوعی و به سبک امیر هستند، نه پاسخ زنده شخص او. پیام `/start` فقط یک سلام کوتاه است. پرسش مستقیم درباره انسان/ربات بودن باید صادقانه پاسخ داده شود. گفتگو روی شنیدن، شناخت کار و هدف مخاطب و یک قدم عملی کوچک متمرکز است؛ نه فشار، سرزنش یا تضمین موفقیت. پاسخ واقعی وابسته به پیروی مدل از دستور است؛ پیش از استفاده عمومی با مدل منتخب تست کنید.

پس از انتشار این تغییر، برای آزمون لحن جدید `/start` یا `/reset` بفرستید تا پیام‌های قدیمی روی شخصیت گفتگو اثر نگذارند.

## پاسخ کوتاه و نظر

پاسخ‌های معمولی کوتاه، همراه با ایموجی‌های مرتبط هستند. نظر مشخص مدل در کادر نقل‌قول تلگرام نمایش داده می‌شود؛ شیشه‌ای واقعی پشتیبانی نمی‌شود. احوال‌پرسی ۲۴ ساعت بعد فقط در [نسخهٔ Cloudflare](CLOUDFLARE.md) با اطلاع کوتاه یک‌باره و امکان لغو پایدار (`/stop` یا `/reset`) پیاده‌سازی شده؛ اجرای محلی زمان‌بندی ندارد.
