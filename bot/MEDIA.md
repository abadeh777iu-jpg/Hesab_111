# عکس و ویس با Free.ai؛ چت با OpenRouter

این قابلیت فقط در نسخهٔ Cloudflare فعال است. از این نسخه، سرویس پیش‌فرض **فقط عکس و تبدیل متن پاسخ به صدا، Free.ai است**. نوشتن جواب، چت عادی، جملهٔ هوا و تست برف همچنان OpenRouter هستند. کلید OpenRouter را عوض نکنید. هیچ خرید، اشتراک یا شارژ تازه‌ای انجام نشده است.

## اتصال با گوشی

۱. در Cloudflare وارد Worker با نام `hesab-111` شوید.
۲. **Settings → Variables and Secrets → Add** را باز کنید.
۳. نوع **Secret**، نام `FREEAI_API_KEY` و مقدار **کلید خود Free.ai** را وارد کنید؛ Save / Deploy بزنید. کلید را در تلگرام، این گفتگو، گیت‌هاب یا اسکرین‌شات نفرستید. کلید Free.ai را جای `OPENROUTER_API_KEY` نگذارید.
۴. پس از انتشار موفق، در تلگرام تست کنید:

```text
/image یه کلبه چوبی وسط برف، نور گرم پنجره‌ها
```

این درخواست، یک عکس از مدل پیش‌فرض `sdxl` می‌خواهد و آن را به‌صورت فایل تلگرام ارسال می‌کند. «برام یه عکس کلبه برفی بساز» هم کار می‌کند. صرف اشاره به عکس، درخواست تولید تصویر ایجاد نمی‌کند.

### فعال‌کردن ویس فارسی: نیازمند نام مدل و صدای تأییدشده

نمونهٔ SDK رسمی Free.ai پیش‌فرض انگلیسی دارد. وجود گزینهٔ Persian در صفحهٔ وب، به‌تنهایی نام مدل و صدای قابل استفاده با کلید API شما را اثبات نمی‌کند. نام یا شناسهٔ صدای فارسی را حدس نمی‌زنیم و Kokoro انگلیسی را برای فارسی پیش‌فرض نمی‌کنیم.

در پنل Free.ai یک مدل و صدای **واقعاً فارسی** را امتحان و شناسهٔ API آن‌ها را از راهنما/پشتیبانی همان سرویس تأیید کنید. سپس در Cloudflare دو متغیر **Text** بسازید:

- `FREEAI_TTS_MODEL`: شناسهٔ دقیق مدل فارسیِ پشتیبانی‌شده در حساب شما.
- `FREEAI_TTS_VOICE`: شناسهٔ دقیق صدای فارسیِ همان مدل.

این دو نام محرمانه نیستند؛ می‌توانید فقط نام‌ها را برای تنظیم بفرستید، نه کلید، هدر Authorization یا لینک فایل دارای توکن. تا وقتی هر دو تنظیم نشده‌اند، `/voice` پیام راهنمای تنظیم می‌دهد و **هیچ بودجه یا اعتبار API برای آن درخواست مصرف نمی‌کند**؛ به OpenRouter یا یک صدای انگلیسی هم سوییچ نمی‌کند.

پس از تنظیم:

```text
/voice چطور کارمو شروع کنم؟
```

متن پاسخ با OpenRouter نوشته و ارسال می‌شود؛ سپس **فقط همان متن** برای تبدیل به صدا به Free.ai می‌رود. درخواست صوت صریحاً `language: fa` و `format: mp3` دارد. پشتیبانی واقعی مدل از این فرمت و تلفظ فارسی باید در حساب شما بررسی شود. MP3، OGG/Opus و M4A سازگار پذیرفته می‌شوند؛ WAV، OGG/Vorbis و فایل ناسازگار، بدون تبدیل پولی یا retry رد می‌شوند و متن پاسخ باقی می‌ماند.

اگر پاسخ گفتگویی قبلی در تاریخچهٔ فعال دارید، `/voice` بدون سؤال همان را می‌خواند؛ برای نوشتن دوبارهٔ جواب، هزینهٔ مدل چت ندارد ولی ساخت صوت سهمیه و اعتبار Free.ai را مصرف می‌کند. «با ویس جواب بده، چطور شروع کنم؟» هم پشتیبانی می‌شود.

صدای خروجی، صدای آمادهٔ مصنوعی است، **نه صدای واقعی صاحب ربات**؛ caption این موضوع را روشن می‌کند. ورودی صوتی، تحلیل یا ویرایش عکس، تقلید صدا و ارسال جمعی اضافه نشده‌اند.

## محدودیت مصرف ثابت مانده است

- کل ربات در یک روز UTC: حداکثر **۱۰ تلاش عکس و ۱۰ تلاش ویس**.
- هر مخاطب: حداکثر **۵ تلاش عکس و ۳ تلاش ویس** در همان روز.
- فاصلهٔ دو درخواست رسانهٔ یک مخاطب: حداقل **یک دقیقه**.
- توضیح ورودی: حداکثر ۲۰۰۰ کاراکتر؛ گفتار: حداکثر ۶۰۰ کاراکتر؛ سؤال صوتی: حداکثر ۳۲۰ توکن پاسخ چت هم مصرف می‌کند.
- بودجهٔ مشترک، قبل از تماس با سرویس، در Durable Object سریالی رزرو می‌شود؛ این آمار تعداد کاربران نیست، فقط سقف درخواست رسانه است.
- تنظیم ناقص سرویس پیش از رزرو و تماس تشخیص داده می‌شود. پس از رزرو، خطای سرویس، محدودیت محتوا، timeout، فایل ناسازگار یا شکست ارسال هم سهمیهٔ تلاش را مصرف می‌کند. بازپرداخت سهمیه، retry یا fallback پولی خودکار نداریم.
- `/reset`، `/start`، پایان تاریخچه و بازسازی شیء، سهمیهٔ روز را صفر نمی‌کنند. مرز روز، نیمه‌شب UTC است، نه ساعت ایران.
- شهر و اشتراک احوال‌پرسی/هوا تغییر نمی‌کنند؛ رسانه فقط به همان مخاطب درخواست‌کننده می‌رود. `/stop` پیام خودکار را می‌بندد، نه پاسخ به درخواست دستی.
- قطع اجرا پس از رزرو ممکن است پاسخ را از دست بدهد؛ تحویل exactly-once تضمین نمی‌شود.

**Free.ai به معنی رایگان و نامحدود نیست.** سهمیهٔ رایگان، نرخ توکن و دسترسی مدل تابع پلن حساب است. سقف تعداد درخواست، سقف دلاری تضمین‌شده نیست؛ محدودیت اعتبار را در پنل سرویس هم تنظیم کنید. مدل premium به‌طور خودکار انتخاب نمی‌شود. هزینهٔ چت و جملهٔ هوا در OpenRouter جداست.

## تنظیمات اختیاری مدیر

| نام | پیش‌فرض | کاربرد |
| --- | --- | --- |
| `MEDIA_PROVIDER` | `freeai` | فقط سرویس رسانه؛ تنظیم چت را تغییر نمی‌دهد |
| `FREEAI_API_KEY` | لازم، Secret | فقط به API ثابت Free.ai فرستاده می‌شود |
| `FREEAI_IMAGE_MODEL` | `sdxl` | شناسهٔ مدل تصویر از فهرست Free.ai، با پاسخ هم‌زمان `image_url` |
| `FREEAI_TTS_MODEL` | بدون پیش‌فرض | نام مدلِ تأییدشده برای فارسی |
| `FREEAI_TTS_VOICE` | بدون پیش‌فرض | شناسهٔ صدای فارسی همان مدل |
| `MEDIA_ENABLED` | فعال | مقدار دقیق `false` عکس و ویس را بدون قطع چت خاموش می‌کند |

آداپتور قبلی OpenRouter فقط برای بازگشت **آگاهانهٔ مدیر** با `MEDIA_PROVIDER=openrouter` باقی مانده؛ هیچ fallback خودکار به آن وجود ندارد. در این حالت تنظیمات قبلی `OPENROUTER_IMAGE_MODEL`، `OPENROUTER_SPEECH_MODEL` و `OPENROUTER_VOICE` اعمال می‌شوند. پیش‌فرض‌های آن به‌ترتیب `bytedance-seed/seedream-4.5`، `openai/gpt-4o-mini-tts-2025-12-15` و `onyx` هستند. مقدار ناشناختهٔ provider به‌جای تماس حدسی، رد می‌شود.

هیچ binding، migration یا webhook تازه‌ای نسبت به نسخهٔ رسانهٔ قبلی لازم نیست. binding فعلی `MEDIA` و migrationهای `v1` تا `v3` را حفظ کنید. کلید تازه فقط در داشبورد، نه در فایل مخزن، وارد شود.

## دریافت امن فایل و حریم خصوصی

Free.ai برخلاف آداپتور قبلی، URL فایل را در پاسخ JSON برمی‌گرداند. برنامه فقط خروجی‌های HTTPS در مسیر `/static/outputs/` روی میزبان دقیق `api.free.ai` یا `free.ai` را می‌گیرد؛ URL نسبی همین مسیر هم پذیرفته می‌شود. دامنهٔ دیگر، IP خصوصی، userinfo، پورت سفارشی، مسیر کدشده و ریدایرکت مجاز نیست. **هیچ کلید یا cookie برای دانلود فایل فرستاده نمی‌شود.** فایل با سقف واقعی ۵ MiB خوانده، MIME و امضای آن بررسی و باینری با multipart به تلگرام ارسال می‌شود؛ URL خروجی مستقیماً به تلگرام سپرده نمی‌شود.

اگر سرویس از CDN یا مسیر دیگری فایل بدهد، دریافت عمداً متوقف می‌شود؛ فقط نام میزبان و مسیر عمومی را بدون query/توکن برای بررسی بفرستید. allowlist یا ریدایرکت را برای رفع سریع غیرفعال نکنید. پاسخ job/async، polling و تبدیل فرمت پولی در این نسخه پیاده‌سازی نشده‌اند.

توضیح عکس بدون شناسهٔ تلگرام یا تاریخچهٔ گفتگو به Free.ai می‌رود. سؤال صوتی مانند چت معمولی با تاریخچه به OpenRouter می‌رود و فقط متن جواب به Free.ai فرستاده می‌شود. فایل خروجی Free.ai ممکن است روی URL عمومی سرویس بماند؛ محرمانه‌بودن لینک، سیاست نگهداری یا حذف خودکارش را تضمین نمی‌کنیم. اطلاعات حساس نفرستید.

این برنامه فایل را روی دیسک یا در لاگ نمی‌نویسد؛ توضیح عکس در تاریخچه ثبت نمی‌شود. سؤال و پاسخ صوتی تولیدشده مثل چت معمولی تا ۳۰ پیام و ۳۰ دقیقه نگه داشته می‌شوند. بودجهٔ شخصی فقط شمار تلاش‌ها و زمان‌های محدودیت را تا پایان روز نگه می‌دارد؛ بودجهٔ مشترک هیچ شناسه، متن یا فایلی ندارد. پاک‌سازی با alarm انجام می‌شود. حذف محلی، سوابق و فایل‌های تلگرام، OpenRouter یا Free.ai را حذف نمی‌کند. خطاهای خام و URL حاوی توکن ثبت یا نمایش داده نمی‌شوند.

## منابع و آزمون

- API رسمی: https://free.ai/api/
- فهرست مدل‌ها: https://api.free.ai/v1/models
- صفحهٔ گفتار و گزینه‌های زبان/فرمت: https://free.ai/text-to-speech/
- SDK رسمی بررسی‌شده، نسخهٔ 0.3.0: https://pypi.org/project/free-dot-ai/
- OpenAPI (مسیرهای تولید و فایل‌های `/static/outputs/`): https://api.free.ai/openapi.json

`npm run test:bot` و تست‌های واقعی workerd/Miniflare، جداسازی کلیدها، مسیرها، دانلود بدون اعتبارنامه، فایل multipart، محدودیت‌ها، خطاهای امن و نبود fallback را با upstream ساختگی بررسی می‌کنند. `npm run bot:cf:check` bundle را بررسی می‌کند. هیچ کلید واقعی در این محیط موجود نیست؛ آزمون پولی یا تحویل واقعی تلگرام انجام نشده و نام صدای فارسی API هم هنوز تأیید نشده است. پس از تنظیم کلید/مدل/صدا و انتشار سبز، تست واقعی از سهمیه و اعتبار حساب مصرف می‌کند.
